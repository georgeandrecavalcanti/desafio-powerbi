# 📊 Dashboard de Vendas e Lucros — Power BI

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático de análise de dados utilizando o Microsoft Power BI.

O objetivo é explorar os dados financeiros e apresentar informações sobre vendas, lucros e unidades vendidas, organizadas por país e segmento de mercado.

## Objetivos da análise

- Analisar as vendas por país.
- Comparar o lucro entre diferentes países.
- Visualizar a distribuição do lucro por segmento de mercado.
- Desenvolver um dashboard interativo para facilitar a interpretação dos dados.

## Visualizações desenvolvidas

### 🌎 Mapa de Vendas por País
Mapa interativo com bolhas que representam o volume de vendas de cada país.

### 💰 Mapa de Lucro por País
Mapa interativo que permite comparar os valores de lucro entre os países.

### 🥧 Lucro por Segmento
Gráfico de pizza que apresenta a participação percentual de cada segmento no lucro total.

## Ferramenta utilizada

- Microsoft Power BI Desktop
